## Performance and policy

- Offline mode prewarms a downloaded/unlocked model and keeps it ready by default. “Keep the model ready” can be disabled to unload after one idle minute. API mode releases the local worker.
- Earlier native IPC samples: 1.394 s cold and 0.245–0.269 s warm. Later samples during heavy host load (load average about 23): 1.097–2.345 s warm. Observed worker RSS varied about 630–785 MiB. These measurements exclude capture, popup and cloud/provider latency and do not establish comparative speed.
- Automatic mode now prepares and retains one hidden popup, avoiding WebKit recreation after every ten-second pause. This trades some idle memory for lower startup latency. Debug diagnostics distinguish generation-checked first selection-to-ready paint, offline queue wait and inference; menu resizes no longer count as translation renders.
- The latest slow interaction occurred during extreme shared-host load (reported load averages about 328/286/259 and roughly 10.9 GB swap used). The warm worker had been paged down to about 5.6 MiB resident. Other tasks were left untouched. Earlier quiet-host engine samples do not predict responsiveness in this state.
- Current candidate measured one real accepted selection at 10,023 ms to first ready paint: loading at about 77 ms, queue wait 0 ms, native inference 9,980 ms and about 9 ms from completion to ready render. The popup was reused (one creation). A later completed request in the same candidate measured 327 ms from acceptance to ready, 1 ms queue/initialization and 165 ms inference. These are current-host observations, not a speed guarantee or a physical mouse-up timing measurement.
- Event-driven mouse selection uses 60 ms native settling and 30 ms dispatch delay; keyboard selection debounce is 150 ms. The fallback poll remains bounded at 600 ms. The current measurement starts at backend selection acceptance; physical selection-gesture latency is not instrumented.
- Optimized local .app build passed at 10.38 MiB (10,885,214 bytes), with all three runtime/model notices present. Executable SHA-256: `08566bf8e94d395ca7548c2ac21c3eb96bb9617912880914ed06ac90a9f33764`. This release candidate precedes the latest popup refinements. The latest debug bundle built successfully at about 47.09 MiB.
- Tray-only release measurement (API mode, automatic off, no windows/model): main 72.4 MiB RSS plus reader 32.0 MiB, summed RSS 104.5 MiB. Mean CPU was 0% over five seconds at `ps` timing resolution; no new WebKit process appeared. Summed RSS is not a physical-memory footprint or an active-capture measurement.
- Two superseded task-downloaded original model weight blobs were removed after checking all references, ownership and open files. Verified int8 model, reusable caches and current products were preserved. Actual statvfs free-space increase was 3.574 GiB (76,416,872,448 to 80,254,119,936 bytes).
